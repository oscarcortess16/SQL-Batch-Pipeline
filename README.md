# BATCH INGESTION PIPELINE WITH SQL FROM AN S3 BUCKET
This repository contains the implementation of a modern datahouse architecture for some data samples from customers and products. The project follows the Medallion Architecture approach (Bronze, Silver, and Gold layers) to ingest, process, transform, and analyze data efficiently and scalably.

The solution demonstrates how to build an end-to-end data platform using Databricks, Delta Lake, and cloud-native data engineering practices. It includes raw data ingestion, data cleansing and enrichment, business-ready transformations, and analytical datasets designed for reporting and decision-making.

# Key Features:
- Medallion Architecture implementation (Bronze / Silver / Gold)
- Scalable ETL/ELT pipelines
- Data quality and transformation workflows
- Modular and production-oriented Lakehouse design
# Tech Stack:
- MySQL
- DATABRICKS Autoloader
- Cloud Storage Integration
